# Requirement traceability

Maps each Part 11 requirement to its implementation and to the automated tests that exercise it. Test names are `Class.Method` (xUnit); the project is shown in the first column of each group. Run all of them with `dotnet test` (add `SIGNATURES_TEST_PG` to include the PostgreSQL variants, marked **PG**).

Test projects: **Core** = `RecordSignatures.Core.Tests`, **DB** = `RecordSignatures.Database.Tests`, **API** = `RecordSignatures.Api.Tests`.

## Coverage

With `SIGNATURES_TEST_PG` set, line coverage measured with coverlet across the three source projects is **100%** (`RecordSignatures.Core`, `RecordSignatures.Database`, `RecordSignatures.Api`). Generated EF migrations and the design-time factory are excluded in `coverage.runsettings`. Reproduce:

```bash
SIGNATURES_TEST_PG="Host=localhost;Port=5433;Username=signatures_app;Password=dev-only-change-me;Database=postgres" \
  dotnet test --settings coverage.runsettings --collect:"XPlat Code Coverage"
```

Coverage proves code was executed, not that the requirements are right; the table above is the argument for the latter.
